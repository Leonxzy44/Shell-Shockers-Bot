# ⚙️ About

A self-made Shell Shocker bot that has abilities to **track players**, **move** and **shoot**.
- Code is made in the clear JavaScript.
- This repo isn't allowed to copy the code or change it - download the raw code, and enjoy the game!

# 📜 How to setup the bot

JS Shell Shockers guide:

1. Open Shell shockers on Google Chrome or Microsoft edge.

2. Join the server of the game.

3. Use Developer's tools by pressing F12 on PC or Laptop.

4. Create new file.

5. Copy & Paste code from repository.

6. Hit Enter.

Make sure you code is opened while you bot is in game.

Enjoy!
